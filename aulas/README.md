# Curso de React — Diário de aulas

Acompanhamento da playlist **Curso base de React 2025**, do canal Lucas Souza Dev:
https://www.youtube.com/playlist?list=PL29TaWXah3iYzP5FGywXezXm4ZvBibGSk

Repositório do instrutor (um commit por etapa): https://github.com/lvsouza/curso-base-de-react

## Como usar

1. Assista a aula e reproduza o código no projeto.
2. Leia o `README.md` da aula em `aulas/aula-XX/` para revisar os conceitos e preencher "Minhas anotações".
3. Faça os exercícios de `exercicios/aula-XX/`, de preferência sem olhar o vídeo.
4. Marque o que concluiu na tabela abaixo.

Ritmo sugerido: 3 aulas por dia.
